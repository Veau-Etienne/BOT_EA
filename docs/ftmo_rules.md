# Règles FTMO Et Contraintes Internes

## Compte De Référence

- Type : FTMO Two Step 100k Day Trading.
- Objectif phase 1 : `10%`.
- Objectif phase 2 : `5%`.
- Max daily loss FTMO : `5%`.
- Max loss FTMO : `10%`.

## Règles Internes Plus Strictes

- Risque par trade : `0.25%` à `0.5%`.
- Stop journalier interne : `1%`.
- Stop total interne : `5%`.
- Pas d'overnight.
- Pas de trade sans stop loss.
- Pas d'EA live sans stratégie validée.
- Risk Guard obligatoire pour tout test EA.

## Interprétation

Une stratégie qui respecte les limites FTMO mais viole les règles internes est rejetée ou retravaillée. Le but est de survivre statistiquement avant de chercher le rendement.
